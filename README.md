# Cricket App

A live cricket score Flutter application with Firebase authentication and match filtering.

## Features
- Live cricket matches
- ODI / T20 / Test filters
- Favorites
- Match details
- Firebase authentication
- Error handling
- Retry system

## Tech Stack
- Flutter
- Riverpod
- Firebase
- REST API
